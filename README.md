# Legacy Tools

**Legacy Tools** is a progression-based Minecraft Fabric mod where forgotten tools from an ancient civilization can be restored through use.

Discover Rusted Tools hidden throughout structures, restore them through regular gameplay, and eventually awaken powerful abilities!

---

# Features

## Four Restoration Stages

Every Legacy Tool progresses through four distinct stages:

- Rusted
- Worn
- Restored
- Perfected

Each stage improves the tool's appearance, performance, and eventually unlocks powerful abilities.

---

## Three Legacy Tools

The mod currently includes:

- Legacy Pickaxe
- Legacy Axe
- Legacy Shovel

Each tool follows its own progression path and possesses unique abilities.

---

## Progression

Restore your tools through normal gameplay.

- **Pickaxe** → Mine ores
- **Axe** → Chop logs
- **Shovel** → Excavate blocks

---

## Passive Abilities

Restored and Perfected tools unlock passive abilities that naturally activate while using the tool.

Examples include:

- Ancient Instinct
- Ancient Harvest
- Ancient Momentum

---

## Active Abilities

Perfected tools awaken powerful memories from the past.

- Echoes of the Caves
- Echoes of the Forest
- Echoes of the Earth

Activate them with **Right Click**.

Each ability has its own duration and cooldown.

---

## Ancient Progress

Every Legacy Tool displays:

- Current restoration stage
- Progress bar
- Progress requirements
- Ability descriptions

You'll always know how close your tool is to the next stage.

---

## Ancient Structures

Legacy Tools can be discovered inside naturally generated structures, including:

- Mineshaft
- Ancient Cities
- Woodland Mansions
- Strongholds
- Dungeons
- Desert Pyramids
- Jungle Temples
- Trial Chambers

Some structures provide better chances than others.

---

## Tool Decay

The strongest tools cannot remain powerful forever.

If a Perfected tool is abandoned for many Minecraft days, its memories slowly fade, and it will gradually decay through previous stages.

Continuing to use the tool preserves its legacy.

---

- Minecraft 26.2

- Fabric API

# For ModJam Judges

Thank you for taking the time to play **Legacy Tools**!

The mod is designed around progression rather than immediate power by crafting. The goal is to discover a forgotten tool, restore it through normal gameplay, and eventually awaken its ancient abilities.

Some mechanics are intentionally subtle and may not be immediately obvious:

- Every tool has unique passive and active abilities.
- Perfected tools unlock both Passive and Active abilities.
- Active abilities are activated with **Right Click**.
- Perfected tools slowly decay if left unused for many Minecraft days.
- Using a tool regularly preserves its legacy and prevents decay.
- Mineshaft and Ancient Cities provide the highest chance of discovering Rusted Tools.
- Tooltips contain progression information, abilities, and important gameplay details.

### Why only three Legacy Tools?

This was an intentional design decision.

Legacy Tools focuses on **builder-oriented gameplay**.

The Pickaxe, Axe, and Shovel naturally accompany players during exploration, mining, terraforming, and building.
A Hoe primarily supports farming, which follows a very different gameplay loop and didn't fit the design philosophy of this first release.

Rather than increasing the number of tools, I chose to focus on making each included tool feel unique, memorable, and polished.
