# Changelog

All notable changes to this project will be documented in this file.

This project follows semantic versioning where possible.

## [1.0.0] - Initial Release

### Added

- Added 12 Legacy Tools across four progression stages:
    - Rusted
    - Worn
    - Restored
    - Perfected
- Added Legacy progression system based on using each tool.
- Added persistent tool memory using custom data components.
- Added stage-specific tool statistics and mining speeds.
- Added unique passive abilities for every Perfected tool.
- Added unique active abilities:
    - Pickaxe: 3×3 Mining
    - Axe: Whole Tree Felling
    - Shovel: 3×3 Excavation
- Added ability duration and cooldown system.
- Added on-screen cooldown indicator.
- Added custom lore-rich tooltips.
- Added custom advancements for restoring and perfecting a Legacy Tool.
- Added custom loot generation in world structures.
- Added progressive decay system for abandoned Legacy Tools.
- Added transformation system allowing tools to decay through previous stages over time.
- Added multiplayer synchronization for tool progression and abilities.
- Added support for Mod Menu.
- Added English localization.
- Added custom textures and models for every Legacy Tool stage.

### Gameplay

- Legacy Tools can be discovered inside various naturally generated structures.
- Tools become stronger through continued use instead of crafting upgrades.
- Perfected tools gain powerful abilities while remaining balanced through cooldowns.
- Forgotten tools slowly lose their memories if abandoned for long periods.
