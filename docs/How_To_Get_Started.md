# Getting Started

## Finding a Legacy Tool

Legacy Tools cannot be crafted.

Instead, explore the world and search chests inside structures such as:

- Mineshafts
- Ancient Cities
- Strongholds
- Dungeons
- Woodland Mansions
- Desert Pyramids
- Jungle Temples
- Trial Chambers

Once you find a **Rusted Tool**, your journey begins.

---

## Restoring Your Tool

Simply use the tool as you normally would.

- Mine ores with Pickaxes.
- Chop logs with Axes.
- Dig blocks with Shovels.

As the tool gains experience, it will progress through four stages:

- Rusted
- Worn
- Restored
- Perfected

Each stage improves both its appearance and its power.

---

## Restored Tools

Once a tool reaches the **Restored** stage, it unlocks:

- A unique passive ability

---

## Perfected Tools

Once a tool reaches the **Perfected** stage, it unlocks:

- A unique active ability
- The passive ability stays from the **Restored** Stage

Each tool has its own abilities, so experiment and discover what they can do.

---

## Don't Forget...

Legacy Tools remember those who use them.

If a tool is abandoned inside a chest for too long, its memories begin to fade, causing it to decay back to an earlier stage.

Carry your tools with you.

A Legacy is meant to be preserved—not forgotten.
