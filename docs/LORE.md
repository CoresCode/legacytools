# Legacy Tools Lore

## The Keepers of Legacy

Long before villages, kingdoms, and even written history, there existed a civilization known only as the Keepers of Legacy.

They believed that a tool should never be replaced. Instead, every strike, every journey, and every discovery became part of the tool itself.

Each tool carried the memories of every owner before it.

Only a tool that inherited enough legacy could become Perfected.

When the civilization disappeared, their tools were scattered across the world.

A curse remained.

A forgotten tool slowly loses its memories.

If abandoned for too long, it begins to decay, eventually returning to its Rusted form.

Only by continuing to use the tool can its legacy live on.
